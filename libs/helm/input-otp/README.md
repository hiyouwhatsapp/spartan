# @spartan-ng/helm/input-otp

Secondary entry point of `@spartan-ng/helm`. It can be used by importing from `@spartan-ng/helm/input-otp`.

## Field accessibility

Inside an `hlmField`, the focusable input automatically references the Field description and any visible validation error. Pass `aria-describedby` to add custom description IDs.

The input follows the error state matcher. Use `forceInvalid` on `hlm-input-otp` to mark the entire control invalid, or pass `aria-invalid` to override only the announced state.
